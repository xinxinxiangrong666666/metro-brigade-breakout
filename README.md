# 地铁旅团弹射：城市突围

手机横屏 H5 弹射 Roguelike。深圳地铁五站城市突围 —— 弹射清障 + 技能成长 + 景点明信片收集。

---

## 🎮 怎么玩（选一种）

### 方式 A：双击启动（推荐，最省事）

双击项目根目录下的：

```
双击启动游戏.bat
```

它会自动起服务、自动挑空闲端口、自动打开浏览器。

出现一个黑窗口显示 `服务已启动（多线程模式）` 就说明成功了，浏览器会自己弹出来。
**玩的时候保持黑窗口开着**，关掉窗口就停止服务。

> 如果 `.bat` 一闪而过关掉了，说明系统里没装 Python 或没加进 PATH。
> 去 https://www.python.org/downloads/ 装一个，安装时**务必勾选 `Add Python to PATH`**。

### 方式 B：命令行启动

```bash
cd 地铁旅团弹射-城市突围-源码结构版-v0.6
python 启动游戏.py
```

同样会自动开浏览器。

### 方式 C：手动起服务（不推荐）

```bash
cd 地铁旅团弹射-城市突围-源码结构版-v0.6
python -m http.server 8080
# 然后浏览器打开 http://127.0.0.1:8080/index.html
```

⚠️ **这种方式在 Windows 上容易卡住打不开**，原因见下面「常见问题」第 1 条。
建议直接用方式 A 或 B。

## ❗ 常见问题

### 1. 页面一直转圈 / 打不开 / 白屏

**原因**：`python -m http.server` 是**单线程**的。Chrome / Edge 为了加速会同时开好几条
预连接（keep-alive），第一条连接就把这个唯一的处理线程独占了，后面的请求全排队 ——
表现就是终端显示 `Serving HTTP on ...` 一切正常，但浏览器就是转圈。

**解决**：用 `双击启动游戏.bat` 或 `python 启动游戏.py`。
启动器内置的是 `ThreadingTCPServer`（多线程），并发请求实测 6 条 0.01 秒全部返回。

如果之前手动起的 `http.server` 卡死了，先关掉它那个终端窗口（或 Ctrl+C），再用启动器。

### 2. 不能直接双击 `index.html`

会白屏。因为 `styles.css`、`src/game.js`、`assets/*.png` 都是外部资源，
浏览器在 `file://` 协议下会因 CORS 策略拒绝加载它们。**必须走 HTTP 服务**。

> 需要一个能直接双击打开的版本？用同目录旁边的
> `地铁旅团弹射-城市突围-可玩整合版-v0.6/index.html`（单文件版，所有资源内联为 base64，
> 双击即开）。现场路演建议用单文件版，更不容易出意外。

### 3. 端口 8080 被占用

启动器会自动往下试 `8090 → 8123 → 8765 → 9080 → 9123`，全占了就随机分配一个高位端口。
实际用的地址会打印在黑窗口里，照着打开就行。

### 4. 手动查看 8080 上是谁在占

```powershell
netstat -ano | findstr :8080
# 拿到最后一列的 PID，然后：
taskkill /PID <PID> /F
```

### 5. 改了代码刷新看不到变化

启动器已经强制 `Cache-Control: no-store`，正常刷新（F5）就能看到最新代码。
如果还是不行，按 `Ctrl+Shift+R` 硬刷新。

## 🎯 玩法

**核心循环**：瞄准 → 弹射 → 方块下压 → 清空过关 → 学技能 / 升级 → 下一站

| 操作 | 说明 |
|---|---|
| 按住并拖拽 | 瞄准，会显示预测弹道 |
| 松手 | 发射一轮弹珠 |
| 右上角 `II` | 暂停 |
| 左下角 `▾` | 收起 / 展开技能面板（挡视野时点它） |

**五站线路**

| 站 | 关卡名 | 事件 |
|---|---|---|
| 1 | 高新园 1-1 | 集合教学 |
| 2 | 南头古城 1-2 | 窄巷反弹 |
| 3 | 前海湾 1-3 | 换乘通道 |
| 4 | 前海石公园 1-4 | 海风助推 |
| 5 | 深中通道 1-5 | 长桥穿越 |

每站通关掉落一张景点明信片，五站收集齐进入全线结算。

**三个角色**

| 角色 | 特性 |
|---|---|
| 阿杰 | 首击伤害 +30% |
| 小川 | 反弹后伤害提升 |
| 小夏 | 多显示 1 次反弹预测 |

**方块类型**

| 类型 | 说明 |
|---|---|
| creature | 生物方块，基础血量 |
| stone | 石块，血量 +1 |
| armor | 装甲块，血量 +2 |
| crate | 木箱 |
| loot | 金色宝箱，掉落技能（打破可学新技能） |
| boost | 加速踏板 |

**失败与重试**

体力（♥）归零不会清空进度 —— 回到线路图，体力恢复满，**保留已通关的站点、已学技能和升级**，
可以从当前站重新挑战。只有全线通关后点「再来一局」才会整局重置。

## 🔧 开发说明

- 单文件（`纯 HTML/CSS/JS`），零构建、零依赖、零框架
- Canvas 逻辑分辨率固定 `1280×720`，CSS 等比缩放适配屏幕
- 玩法底座来自 v0.5《像素旅团：弹射远征》，主题换皮为深圳地铁城市突围
- 调试用 QA 模式：地址后加 `?qa=1`，右下角会出现「一键清关」按钮
- 浏览器 Console 里可用 `__PIXEL_VOYAGE__.snapshot()` 查看当前游戏状态

```js
__PIXEL_VOYAGE__.snapshot()      // 查看 mode / level / lives / routeProgress / blocks
__PIXEL_VOYAGE__.completeLevel() // 立即清空本关方块
__PIXEL_VOYAGE__.aimAt(x, y)     // 朝指定方向发射
```

详细版本改动见 `VERSION.md`。
